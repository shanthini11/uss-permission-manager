# Permission Manager

**Course:** Usable Security and Privacy (USS)
**Group:** 8

## Project Overview

Permission Manager is an Android application designed to help
users view, understand and manage application permissions.

The project aims to improve permission transparency, privacy
awareness and user control over sensitive application data.

## Technology Stack

- Kotlin
- Android Studio
- Jetpack Compose
- Android SDK

## Current Development Status

Phase II – Development

The initial Android Studio project has been created.
Core features are currently under development.

## How to Run

1. Install Android Studio.
2. Clone or download this repository.
3. Open the project in Android Studio.
4. Allow Gradle synchronization to complete.
5. Select an Android emulator or connected device.
6. Select the app configuration and click Run.
